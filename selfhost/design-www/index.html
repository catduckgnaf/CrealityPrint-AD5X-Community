AD5X Design workspace

The Design bridge is running, but the built Design web assets are not bundled in this image yet. The Design source (design/) was published after the RC1 tag this image is based on, and its production build (npm ci && npm run build → dist/) has not been wired into the image build yet.

To use Design today, build it from the fork's master branch and mount the output over /opt/crealityprint/bin/External_Runtime_Dependency_AD5X_Design_Service_20261025/www in the container. See selfhost/SELFHOST.md.
